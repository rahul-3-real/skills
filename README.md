# Skills

A collection of reusable skills for AI coding agents.

## Install

Run either command in your terminal and follow the prompts to select the skills and agents you want to install them for.

### Using Bun

```sh
bunx skills add https://github.com/rahul-3-real/skills
```

### Using npx

```sh
npx skills add https://github.com/rahul-3-real/skills
```

Use the Bun command if you have Bun installed, or the npx command if you have Node.js and npm installed.
